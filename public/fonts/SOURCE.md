# Noto Sans Mono

The variable font is distributed by Google Fonts from
`google/fonts/ofl/notosansmono/NotoSansMono[wdth,wght].ttf`.
The SIL Open Font License is retained in `OFL.txt`.

The existing Noto Sans Mono family is bundled locally so production builds do
not need a connection to Google Fonts. `next/font/local` retains the existing
`--font-noto-mono` variable, normal style and weight range.

# Hermes Avatar Assets

The avatar is the official Hermes Desktop application icon from

`NousResearch/hermes-agent` at `38cc3feb67dd82455ac1deeb3120cf73ecf308a2`:

- `apps/desktop/assets/appx/Square44x44Logo.targetsize-256_altform-unplated.png`
- `website/static/img/favicon.ico` (browser ICO)

The original avatar is preserved as `hermes-avatar.png`. Browser/PWA PNG sizes
and legacy URL aliases are derived with `node bin/generate-hermes-icons.mjs`.
No visual content is redrawn or generated. The upstream license is retained in
`HERMES-LICENSE.txt`. These assets identify this self-hosted Hermes interface;
they do not imply that this project is the official Hermes application.
